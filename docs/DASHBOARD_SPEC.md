# Dashboard Specification

1. **Release Overview** — baseline vs candidate, PASS/WARN/BLOCK and blocking reasons.
2. **Capability & Multi-Run** — pass@1/pass@k/all-k and task distributions.
3. **Trace Comparison** — observable actions, tools, loops, errors, cost and latency.
4. **Calibration** — Brier, reliability curve, AUROC, risk-coverage.
5. **Robustness** — perturbation/fault degradation heatmaps.
6. **Failure Explorer** — evidence events, taxonomy, grader/environment status.
7. **Recovery & Safety** — recovery gains, intervention cost, violations/severity.
8. **Cost / SLO** — cost/success, p50/p95 latency, budgets, Pareto frontier.
9. **Tool Contracts** — MCP schema changes, negative tests, side-effect policy.
10. **Incident Regression Set** — incidents converted to golden tests.
11. **Longitudinal Drift** — agent/model/scaffold version changes over stable slices.
12. **Run Audit** — exact task/env/agent/prompt/tool hashes, seed, conditions, grader, cost, commit.
