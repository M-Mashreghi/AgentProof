# Runbook

Suspicious high reliability: check memory/cache leakage, hidden answers, environment reset, grader bug, version mismatch.
Perfect fault robustness: verify faults actually fired.
Recovery gains with high cost: report both and show Pareto frontier.
Perfect confidence: verify confidence precedes outcome and has no gold leakage.
Grader disagreement: classify ambiguous/grader error, do not blame agent automatically.
