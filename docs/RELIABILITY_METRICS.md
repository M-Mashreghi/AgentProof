# Reliability Metrics

1. Capability: success, pass@1, pass@k, completion time.
2. Consistency: all-k reliability, outcome agreement, resource variance, trajectory diagnostics.
3. Predictability: Brier, calibration, AUROC, risk-coverage / E-AURC-style diagnostics.
4. Robustness: base vs prompt/structural/fault conditions.
5. Recovery: recovered success, intervention precision, cost overhead.
6. Safety: domain-specific constraint violations, reported separately.
7. Economics: cost/task, cost/success, tools, tokens, wall time, Pareto frontier.

Aggregate reliability is disabled by default; if enabled, formula must be explicit.
