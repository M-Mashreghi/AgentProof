# Evaluation Protocol

1. Benchmark quality: version, reset, grader, hidden-answer protection.
2. Capability: success, pass@k, completion.
3. Consistency: all-k, outcome/resource variance, trajectory diagnostics.
4. Predictability: calibration, Brier, AUROC, risk-coverage.
5. Robustness: prompt, structural, faults.
6. Recovery: success + overhead.
7. Safety: violations + severity.
8. Economics: cost/task, cost/success, tool usage, latency.

Negative/null results and benchmark defects remain in the report.
