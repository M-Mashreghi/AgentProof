# Benchmark Strategy

AgentProof wraps benchmarks behind one reliability protocol.

## Princeton HAL
Motivates consistency, predictability, robustness, safety, and cost-aware evaluation.

## GAIA
Multi-step reasoning and tool/web tasks.

## τ-bench
Stateful tool-use/customer-service tasks with policy constraints.

## SWE-bench Verified
500 human-validated software-engineering instances; pin harness/scaffold versions.

## OSWorld / OSWorld 2.0
Real computer/GUI tasks; environment image/version is critical.

## TUA-Bench
Terminal-use execution tasks; useful for repeated-run/all-k reliability.

## Agents' Last Exam
Long-horizon professional tasks across many occupations; advanced integration where access permits.

Each adapter declares support for reset, exact grading, perturbations, faults, cost, trajectories, safety, and environment snapshots.
